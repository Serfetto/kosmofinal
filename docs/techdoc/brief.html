AquaFlow — веб-сервис для специалиста по экологическому мониторингу. Пользователь выбирает акваторию и дату снимка Sentinel-2 и получает на карте зоны вероятного скопления плавающего мусора с маской качества снимка, полевые измерения из реестра кейса и модельную концентрацию в шт./км² с интервалом и статусом доверия. Результаты выгружаются в GeoJSON, CSV и PDF, сохранённый запрос повторяется с проверкой sha256. Дополнительно: прогноз дрейфа на 72 ч и маршрут судна к скоплениям.

Проверка за 5 минут

  1. docker compose up -d --build → http://localhost:8000: снимки, модели и метрики уже в репозитории.
  2. «Батуми — Кобулети», 05.06.2024 → клик по гексу: интервалы, статус, «Расчёт по шагам»; «Сводка» → «Сохранить» → «Повторить»: sha256 совпадает.

Главная идея: снимок показывает, где искать, поле — сколько

При пикселе 10 м видны плотные скопления и полосы мусора, но не рассеянный мусор: 1000 предметов на км² по 0,01 м² — это ~10 м² на км², десятая часть одного пикселя. Поэтому три величины считаются раздельно и по-разному показаны на карте; площадь зоны детекции в шт./км² не переводится.

Архитектура

pipeline/ заранее считает зоны, гексы, статусы и концентрацию для всех дат, сервис раздаёт готовые файлы из data/web/: снимки (~17 ГБ) для запуска не нужны, выгрузка строится из тех же файлов, что и карта. Стек: Python 3.12, XGBoost, FastAPI, React, MapLibre GL, Docker.

Детектор скоплений

Sentinel-2 L2A, 11 каналов, сетка 10 м→маска воды и облаков (SCL)→нормализация фона→20 признаков→XGBoost, 6 классов→P ≥ 0,5→фильтры→зоны, гексы H3, статусы
  • Нормализация фона — главный шаг: из пикселя вычитается локальный спектр окружающей воды (блоки ~320 м) и прибавляется эталон воды MARIDA. Так уходят блик, дымка и разница атмосферной коррекции между MARIDA (ACOLITE) и нашими снимками (Sen2Cor).
  • Признаки: 11 каналов, индексы FDI, FAI, NDVI, NDWI, PI, NDMI, текстура. Обучение: MARIDA train (694 патча), 15 классов сведены в 6 групп, неразмеченные пиксели не используются.
  • Фильтры: NIR-аномалия сильнее синей (против пены), соседи с P > 0,3 (против шума), CFAR 5σ (против блика и ряби); буферы 100 м от облаков, 400 м от судов, 300 м ото льда; постоянные объекты по ряду снимков; на сценах со штормом ≥8 м/с или сильным бликом — только скопления от 4 пикселей.

Сложный фон и границы

  • Пороги не работают: мутная вода и саргассум дают FDI выше, чем мусор. Фильтры вдвое снижают ложные срабатывания ценой 8% попаданий.
  • Главный источник ошибок на MARIDA — органика и плавник (26% пикселей класса).
  • Регион, исключённый из обучения: F1 в среднем 0,52 (от 0 до 0,91).
  • MADOS содержит MARIDA целиком; на 27 новых сценах F1 0,30: за мусор принимается 45% морской слизи и 38% медуз. Дообучение на MADOS пробовали в трёх вариантах — каждый теряет полосы мусора или ловит плёнки на наших снимках, модель сервиса оставили прежней.

Концентрация в шт./км²

Профиль A — отрицательно-биномиальная GLM числа предметов со смещением log A (у S2 известны N и A):

C = exp(3,889 + 0,290·zlat + 0,421·zlon)

Профиль B — ридж-регрессия; признак — расстояние до берега d, км:

ln(C + 1) = 5,336 − 0,372·(ln(1 + d) − 4,154) / 1,051

Защита от утечек. Разбиение зафиксировано до экспериментов: события одного дня рейса, ближе 30 км и 3 сут. или с общей сценой — одна группа, группа целиком в обучении или в отложенной выборке (~20%). Признаки — только доступные при применении (координаты, расстояние до берега, ветер ERA5); 25 полей, производных от ответа, запрещены и проверяются тестом. Веб-сервис и выгрузка

  • Сценарий: акватория и дата → снимок и его качество (пролёт, облачность, видимая вода, блик, ветер) → зоны и показатель карты → карточка зоны, гекса или измерения → выгрузка.
  • Карта: 9 показателей (концентрация, статус, качество, покрытие, среднее, устойчивость, тренд, скопление, прогноз), 11 слоёв, фильтры по статусам, инструменты «Данные кейса», «Участок», «Сравнить», «Дрейф», «Маршрут», «Методика».
  • Карточки: у гекса — значение, интервалы, причины статуса и «Расчёт по шагам» с коэффициентами; у зоны — площадь отдельно от концентрации и «Почему это мусор» по каждому фильтру; у измерения — N, A, C, источник, флаги и строки реестра.
  • Выгрузка: зоны и гексы в GeoJSON и CSV с единицей, профилем, интервалами, статусом, версией модели; PDF-отчёт с координатами зон. Одинаковый запрос — одинаковые байты (sha256 в заголовке); сохранённый запрос повторяется с проверкой match.
  • API: 37 ручек, /api/docs; ошибки 404/422/503 с текстом по-русски, ни одна ручка не падает с 500 на мусорный ввод (тест).

Дополнительные функции

Прогноз дрейфа на 72 ч — лагранжев ансамбль по течениям SMOC и 1–3% ветра ERA5 с выбросом на берег; проверен без будущих данных на 7 парах соседних снимков: прогноз ближе к новым детекциям только в 2 парах (3,0 км против 1,4 км у «пятно на месте»), поэтому помечен справочным. Дрейф без снимка по реанализам Copernicus Marine для событий 2014–2016 гг. Маршрут судна к скоплениям с поправкой на дрейф к моменту прибытия. Зоны схождения течений, тренды и устойчивость по ряду снимков, сравнение двух участков. Прогнозы на карте всегда подписаны «Прогноз, не наблюдение».

Запуск и проверка

docker compose up -d --build            # → http://localhost:8000; снимки и модели уже в репозитории
python -m pipeline.verify               # секунды: sha256 весов и выборок, P/R/F1/IoU и MAE из предсказаний
python -m pipeline.reproduce --offline  # сквозной пересчёт ~5 мин на CPU, 4 ГБ RAM
python -m pytest -q                     # 125 проверок: формулы, утечки, API, устойчивость
python -m pipeline.field explain S2:MSM41_litter-T18      # разбор одного измерения
python -m pipeline.concentration explain B 39.72 43.55 2025-07-18T08:10

Локально: Python 3.12 + pip install -r requirements.lock, Node.js 20+ для сборки интерфейса. Ключи не нужны; .env с бесплатным аккаунтом Copernicus Marine включает только дрейф без снимка. Полный пересчёт снимков — ~17 ГБ, ~45 мин на GPU.

Ограничения и развитие

  • При 10 м видны скопления (≳20–30% пикселя), а не отдельные предметы; слизь, медузы, плавник спектрально похожи на мусор — нужна проверка судном или дроном.
  • Детектор обучен на тропической MARIDA; для Чёрного моря нужна локальная разметка.
  • У побережья РФ полевых точек нет — там только исследовательская оценка.
  • Разметить подготовленный набор (120 зон, 60 точек) по нашим водам.
  • Совместные кампании «трансекта в день пролёта» — для калибровки «снимок → шт./км²».
  • Второй регион для профиля A (S3, PANGAEA 890781); калибровка дрейфа.
