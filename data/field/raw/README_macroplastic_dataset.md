# Реестр морского макромусора: описание данных

В комплект входит один датасет: `macroplastic_marine_samples.csv`, 935 строк и 56 полей, 318 событий. Формат UTF-8, разделитель запятая, десятичная точка. Пустое поле означает неизвестное или неприменимое значение, а не ноль. Идентификатор sample_id однозначно задаёт запись.

Этот CSV и настоящий README определяют состав и смысл выданных данных. Публикации и внешние таблицы описывают их происхождение и могут использоваться для самостоятельного расширения набора.

Реестр объединяет измерения разными методами, категории мусора и отдельные объектные наблюдения. Команда самостоятельно определяет целевую величину, отбирает совместимые записи, строит спутниковые пары и формирует независимую проверочную выборку. Дополнительные открытые данные разрешены с указанием происхождения и условий использования.

## Смысл измерений

- Суммарный пластик, отдельная категория, весь морской мусор и отдельный предмет обозначают разные совокупности. Их описывают `record_type`, `target_scope`, `material`, `size_class` и `measurement_profile`.
- Размерные классы и методы наблюдения не взаимозаменяемы. Порог S2 около 2 см характеризует оценённый минимальный обнаружимый размер в методике, а не измерение размера каждого предмета.
- Плотность относится к обследованной площади события. Точка на карте может обозначать середину полосы или положение наблюдателя, а не местоположение каждого предмета.
- Плотности, опубликованные как оценки, не всегда восстанавливаются простым делением числа предметов на площадь. Используйте `calculation_method` и сведения первоисточника. Неполный набор объектных строк не позволяет восстановить числитель трансекты простым подсчётом записей.
- Для S2 использована авторская обследованная площадь. У прерванных трансект T18, T22, T35, T49 крайние точки не описывают весь маршрут; сегменты и их время восстанавливаются из публичных таблиц PANGAEA. Для расчётов используется опубликованная итоговая площадь события.
- S3 и S4 содержат показатели общего мусора. Среднюю долю пластика из публикации нельзя автоматически применять к отдельному наблюдению. Для S4 часть числителей, площадей и временных параметров отсутствует.

## Качество, пропуски и ограничения

`quality_flags` описывает свойства происхождения и ограничения измерений. Пустой список флагов не означает полной проверки всех свойств записи.

| Код | Значение для использования данных |
|---|---|
| source_total_vs_object_count_conflict | Суммарная оценка события не имеет однозначного подтверждения по объектным наблюдениям. Производные значения категорий этого события также требуют проверки. |
| source_object_row_not_reconstructed | Детальное соответствие объектной записи первоисточнику не установлено. |
| object_row_match_ambiguous_or_unresolved | Сопоставление объектной записи с источником неоднозначно. |
| source_not_revalidated_in_repair | Объём проверки происхождения записи ограничен. |
| numerator_area_unavailable | Нет числителя или обследованной площади для проверки отношения N/A. |
| all_litter_not_plastic | Показатель относится к общему мусору. |
| object_time_is_parent_interval | Время задано интервалом родительского события. |
| category_dictionary_corrected | Категория описана по словарю источника. |
| size_filter_corrected | Размерная совокупность определяется фильтром источника. |
| start_coordinate_corrected_to_midpoint | Представительная координата задаёт середину трансекты. |
| author_area_replaces_endpoint_distance | Для расчёта используется опубликованная авторская площадь. |
| interrupted_transect_summary_area | Площадь относится к прерванной трансекте в целом. |
| summary_area_rounded_differs_from_segment_sum | В расчёте используется округлённая итоговая площадь события. |
| companion_count_differs_sum_float_items | Правило выбора числителя задано в calculation_method. |
| zero_only_for_defined_scope | Нулевое значение применимо только к указанной совокупности. |

Ноль действителен только для своего материала, размерного класса, категории и метода. Его область задана `zero_scope`. Пустые значения нельзя заменять нулями. `reported_*` и поля с суффиксом `_orig` содержат справочные значения; они не подменяют основные концентрации. `parent_*` описывает родительское событие, а не самостоятельное измерение предмета.

## Самостоятельная подготовка и проверка

Состав и причины отбора наблюдений, преобразования, добавленные источники и правила разбиения команда документирует в своём решении. Строки одного события, связанные предметы и сцены зависимы; разделение обучения и проверки должно учитывать эти связи и пространственно-временное соседство.

Из предикторов модели концентрации необходимо исключить сам ответ и поля, вычисленные из него: концентрации, `items_count`, `density_numerator_items`, `source_object_filtered_items`, `reported_*`, `parent_*` и аналогичные производные. Допустимость признака зависит также от его доступности в заявленном сценарии применения.

Наличие полевой записи не подтверждает наличие пригодного спутникового снимка. Нужно самостоятельно проверить архив, геометрию, время, дрейф, облака, блики и качество воды. Концентрация по полосе не является меткой центрального пикселя. Календарная пригодность миссии не подтверждает найденную сцену. Готовый непрерывный временной ряд реестром не предоставляется.
